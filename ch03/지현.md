# Chapter 03 - 지현

## 핵심 내용

- 클릭으로 하나의 툴팁을 열고 닫는 React 상태 관리 방식을 사용합니다.
- `details`와 `summary`를 이용해 브라우저 기본 상태로 툴팁을 구성합니다.
- 원본 저장소의 툴팁 예제에서 다루는 상호작용과 접근성 패턴을 현재 라우트 구조에 맞게 이식했습니다.

## 예제 코드

- `src/examples/ch03/jihyeon/Example.tsx`

## 실행 방법

```bash
npm run dev
```

브라우저에서 `/ch03/jihyeon` 경로로 접속합니다.

## 메모

- 툴팁은 짧은 보조 설명에 사용하고, 중요한 정보나 필수 동작은 본문에 표시합니다.
